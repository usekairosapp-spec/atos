# Story SCH-001 — Funções configuráveis por setor

## Status

Ready for Review

## História

Como administradora da igreja, quero configurar as funções de cada setor e a quantidade sugerida de vagas, para que os líderes possam montar escalas conforme a realidade do ministério.

## Rastreabilidade

FR-006, FR-007, FR-008, FR-009; BR-002, BR-003, BR-004.

## Critérios de aceite

- [x] Os seis setores recebem suas funções iniciais automaticamente.
- [x] Câmeras possui três vagas sugeridas; demais funções começam com uma.
- [x] Administradora adiciona novas funções a qualquer setor.
- [x] Administradora altera nome e quantidade sugerida.
- [x] Administradora ativa ou arquiva funções sem apagar histórico.
- [x] Líder e membro visualizam somente funções de igrejas às quais pertencem.
- [x] Usuário sem autorização não altera funções diretamente pela API.
- [x] Interface funciona em celular e desktop.
- [x] Lint, tipos, testes e build passam.

## Tarefas

- [x] Criar seed e trigger para funções iniciais.
- [x] Criar policies RLS e índices.
- [x] Criar ações validadas de adicionar, editar e arquivar.
- [x] Criar telas de setores e detalhes das funções.
- [x] Aplicar migration e executar quality gates.

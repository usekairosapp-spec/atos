# Story ADM-001 — Separação entre plataforma e igreja

## Status

Ready for Review

## História

Como administradora da plataforma AppEscala, quero uma Central para administrar igrejas, usuários e responsáveis sem acessar a operação interna de cada igreja.

## Critérios de aceite

- [x] Administradora da plataforma acessa apenas a Central.
- [x] Central mostra igrejas, usuários e administradores responsáveis.
- [x] Administradora da plataforma cria igrejas e designa o administrador geral de cada uma.
- [x] Administradora da plataforma não integra setores nem acessa escalas e comunicados da igreja.
- [x] Administrador geral da igreja aprova membros e designa líderes.
- [x] Líder continua limitado aos próprios setores.
- [x] Membro continua limitado aos próprios dados.
- [x] Suspensão ou remoção revoga acessos setoriais e preserva o histórico de escalas.
- [x] Administrador da igreja remove membros comuns sem afetar administradores protegidos.
- [x] Central da plataforma contabiliza vínculos ativos e pendentes sem conceder acesso operacional à igreja.
- [x] Administrador da igreja pode manter dois ou mais líderes no mesmo setor e retirar uma liderança sem remover o membro.
- [x] Mudanças de liderança revalidam imediatamente o layout e as permissões do painel.
- [x] Igreja possui identidade visual própria com logo, capa e cor configuráveis pela administradora.
- [x] ATOS oferece temas claro e escuro persistidos no dispositivo.
- [x] Lint, tipos, testes, build e schema passam.

## Tarefas

- [x] Ajustar modelo e policies de administração.
- [x] Remover vínculos operacionais de administradores da plataforma.
- [x] Criar RPC segura para designar administrador da igreja.
- [x] Criar Central da plataforma.
- [x] Ajustar redirecionamentos após login.
- [x] Remover seletor de igreja das áreas operacionais.
- [x] Executar quality gates.
- [x] Endurecer helpers de autorização para igreja e memberships ativas.
- [x] Criar remoção transacional de membro e encerrar participações futuras.

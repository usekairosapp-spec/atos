# Story SCH-002 — Criação e publicação de escalas

## Status

Ready for Review

## História

Como líder de setor, quero criar uma escala, distribuir pessoas nas funções e publicá-la, para que cada membro veja seus compromissos.

## Critérios de aceite

- [x] Líder cria escala apenas para setor atribuído.
- [x] Escala possui evento, data, início, fim, local e observações.
- [x] Líder adiciona qualquer quantidade de pessoas por função.
- [x] Apenas membros ativos do setor podem ser escalados.
- [x] Líder salva como rascunho e publica quando estiver pronta.
- [x] Administrador da igreja consulta todas as escalas, mas não altera funções do líder.
- [x] Membro visualiza somente escalas em que foi incluído.
- [x] Usuário sem permissão é bloqueado por RLS/RPC.
- [x] Interface funciona em celular e desktop.
- [x] Data e horários são preenchidos separadamente e é possível adicionar outro culto no mesmo dia.
- [x] Lint, tipos, testes, build e schema passam.

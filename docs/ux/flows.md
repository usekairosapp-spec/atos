# UX e fluxos — AppEscala

## Navegação principal

- Início
- Minhas escalas
- Calendário
- Comunicados
- Perfil

No celular, a navegação usa barra inferior com cinco destinos. No desktop, passa a menu lateral. Notificações ficam no cabeçalho. Igreja e setor funcionam como contexto/filtro, sem exigir contas diferentes.

## Fluxos

### Entrada

Cadastro ou Google → confirmação → perfil → convite/solicitação de igreja → aprovação pela administradora → vínculos com setores.

Estados: vínculo pendente, convite inválido, solicitação recusada, usuário sem setor e conta suspensa.

### Criação de escala

Selecionar setor → evento → data/horário/local → funções e participantes → validar conflitos → salvar rascunho ou publicar → notificar participantes → sincronizar calendário.

### Confirmação

Abrir escala → conferir setor, função e horário → confirmar ou recusar → informar motivo opcional → exibir sucesso com próximo passo.

### Troca

Solicitar troca → informar motivo e sugestão opcional → líder escolhe pessoa elegível → substituto aceita → líder aprova → sistema troca de forma transacional e notifica envolvidos.

### Comunicados

Líder seleciona setor ou participantes de uma escala → escreve título e conteúdo → publica → membros recebem e marcam como lido. Não há resposta.

## Direção visual

Preservar roxo como cor principal e verde para sucesso, com menos sombras e gradientes que as referências. Usar tipografia legível, contraste WCAG AA, alvos de toque de no mínimo 44 px e status sempre identificados por texto, não apenas cor.

A Home prioriza pendências, próxima escala e calendário. O cartão de escala mostra setor, evento, função, horário, local e status.
